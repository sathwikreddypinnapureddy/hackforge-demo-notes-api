# Notes API Demo

A small synthetic notes API created specifically for HackForge security testing.

This repository intentionally contains safe, fake security mistakes so HackForge can demonstrate:

- repository analysis
- Git hygiene detection
- credential detection
- remediation
- deterministic rescanning
- verified security improvement

## Security Testing Notice

All credential-like values in this repository are fake and nonfunctional.

This repository exists only for defensive security demonstrations.
